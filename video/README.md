# Demo video (T3)

The 5-minute demo video is submitted through the **course channel (NTULearn)**,
not via this repository (size limits). This file records what it must contain.

## Required contents

1. **System running end-to-end** on a normal claim — show an approve /
   request-document / escalate decision with the recorded justification.
2. **One negative case reproduced live** (e.g. a lapsed-policy or
   prompt-injection claim) showing the guardrail catch and the escalation written
   onto the record.
3. **A short spoken contribution from each of the six members.**
